\chapter{Summary and Future Work}
\label{ch:summary}

This report developed and evaluated \texttt{mcmc-bench}, a common framework for comparing sampling methods in Bayesian calibration. Five gradient-free samplers were integrated through a shared Nextflow workflow and UM-Bridge model interface.

\section{Summary}
\label{sec:summary}

Regarding RQ1, the implementation shows that sampler-specific environments can be integrated while keeping the surrogate model, statistical problem, and output format fixed. Regarding RQ2, posterior summaries, convergence diagnostics, model evaluations, and sampling time provide a practical comparison of the methods. The samplers produced similar posterior estimates in the mass-flow case study, while dynesty was the most computationally efficient in the single benchmark run.

\section{Future Work}
\label{sec:future-work}

The evaluation should be repeated with multiple runs, more thoroughly tuned settings, higher-dimensional calibration problems, and alternative models. Extending the model interface with gradient information would enable gradient-based samplers, while additional model workers and sampler implementations in other programming languages would broaden the benchmark.
